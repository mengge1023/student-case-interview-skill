# 学员案例访谈

把真实学员经历做成“读者愿意看、看完觉得自己也能做、自然理解课程价值”的案例内容。核心不是把访谈包装成广告，而是用证据、过程和可复用方法建立信任，再让课程成为成功路径中真实存在的一环。

## 先判断任务模式

- 用户要采访学员：读取 [references/interview-guide.md](references/interview-guide.md)，输出主持人可直接使用的主问题、追问和证据准备清单。
- 用户给了学员分享稿/逐字稿并要公众号文章：读取 [references/article-framework.md](references/article-framework.md)，直接产出完整成稿。
- 素材同时需要采访和成稿：先做缺口审计，再给补采问题；已有材料足以支撑的部分可以先成稿，不必因非关键缺口停住。

## 不可破坏的原则

1. 学员素材是事实权威。不得发明身份、时间、收入、利润、销量、投入、课程效果、操作步骤、情绪转折、原话或报名信息。
2. 区分营业额、毛利、净利润、回款、投流消耗、退款与平台费用。口径不完整时明确标为“待核实”，不能自行换算。
3. 保留真实摩擦：失败、低谷、限制条件、做错的动作和修正过程。案例只有结果没有代价，会像广告；只有苦难没有方法，也无法转化。
4. 每个核心方法配一个具体经历或动作证据；不要把访谈压成抽象总结。
5. 课程价值从事实中长出来：具体写清学员在哪一步得到什么路径、反馈、工具、陪跑或同伴支持，以及她如何执行。不要用空泛赞美替代证据。
6. 主持人观点只做解释、提炼和读者异议承接，不抢走学员主体性，不把学员说过的话改造成主持人的功劳。
7. 如果用户提供了自己的课程、价格、日期、权益和行动入口，严格按其最新口径使用；没有提供就以 `【待补】` 标记，不复用对标材料中的商业信息。
8. 默认输出可直接发布的中文正文，不出现“AI总结”“框架分析”“营销设计”等幕后标签。

## 成稿质量标准

- 标题同时包含“可识别的人物起点 + 结果/变化”，但结果必须有来源。
- 开头 300 字内交代人物、结果口径、关键时间和为什么值得听。
- 阅读顺序形成：结果可信 → 我与她相似 → 她经历过失败 → 找到关键变化 → 方法可执行 → 课程如何参与 → 我的疑问被回答 → 我愿意行动。
- 问题短、回答具体；必要时把长回答按一个问题一个主题切开，但不改变因果与口吻。
- 数据、时间线和课程口径在全文一致；重要结果尽量带后台截图、订单、打卡或现场核算等证据占位 `【真实素材待补】`。
- 结尾先让学员给读者一句话，再由主持人自然承接下一步；不突然硬切广告。

## 交付

根据用户输入给出所需组合：

1. 事实卡与证据缺口（仅在确有缺口时）；
2. 采访提纲或补采问题；
3. 可直接发布的公众号全文；
4. 3-5 个标题备选与一段朋友圈/公众号摘要（用户需要传播物料时再给）。
